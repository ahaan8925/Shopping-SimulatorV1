Shopping-SimulatorV1
A command-line shopping cart simulator built in Python.  Users can add items, view their shopping cart, and remove items through an interactive menu system.



Features

- Add items
- View cart
- Delete items
- Interactive menu
- Input validation for item deletion



Technologies

- Python
  

How to Run

python shopping_simulator.py


Example


Main Menu

A: Add Item

R: View Cart

D: Delete Item

E: Exit

Choice: A
